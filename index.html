Mini HTML Glossary

Element
A building block of HTML defined by a start tag, content, and an end tag.
Attribute
Additional information placed inside the start tag of an element.
Semantic HTML
Using HTML elements that carry meaning, like <strong> instead of <b>.
Hyperlink
A clickable reference to another page or location created using the <a> tag.
Image Map
An image with clickable hotspot areas defined by <map> and <area> elements.
Favicon
A small icon displayed in the browser tab, linked via <link rel="icon"> in the <head>.
